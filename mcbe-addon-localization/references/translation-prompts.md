# MCBE 本地化 LLM 提示词模板

Agent 可直接使用或按任务微调以下模板。

## 语言文件 (.lang) 批量翻译

```
你是一名专业的 Minecraft 基岩版模组本地化专家。
请将下面的 .lang 语言文件内容翻译为{lang_label}。

规则：
1. 保持每行格式为 键=翻译后的值，一行一条，行数与输入完全一致
2. 只翻译等号右边的文字，等号左边的键原样保留
3. 保留 %s、%1$s、§c、§l、\\n 等占位符、格式代码、颜色代码完全不变
4. 实体名、物品名、技能名使用游戏内通用的{lang_label}译名
5. 如果值已经是{lang_label}或纯符号，保持不变
6. 不要输出任何解释、前言、结尾，只输出翻译后的行

待翻译内容：
{batch}
```

`{lang_label}` 示例：`简体中文`、`日本語`、`Deutsch`。

## Display Name 回退直译

当无法从 JSON 推导 lang key 时使用：

```
你是一名 Minecraft 基岩版模组本地化专家。
下面是无法标准化为语言文件 key 的 display_name 映射，每行格式为：相对路径=JSON字符串字面量。
请把每个等号右边的显示名翻译成{lang_label}，输出保持原格式（相对路径=JSON字符串），
只改值不改键。注意值需要用 JSON 字符串语法（引号包裹，转义 \\n、§ 颜色码等保留）。
直接输出全部翻译结果，不要任何解释。

内容：
{content}
```

## 脚本提示字符串

```
你是 Minecraft 基岩版模组脚本本地化专家。
下面是从 JS/TS 脚本中提取的玩家可见提示字符串（JSON 数组），请译为{lang_label}。

规则：
1. 只翻译人类可读文字；不要改动代码结构
2. 完整保留 § 及后续格式/颜色码（如 §c、§l、§r）、\\n、\\t
3. 完整保留 ${...} 模板插值、%s、%1$s、{{...}} 等占位符，位置与内容都不要改
4. 已是{lang_label}或纯符号的保持原样
5. 只返回 JSON 数组，每项格式 {"id":"S0000","text":"译文"}，id 与输入一致，不要其它说明

待翻译：
{batch}
```

## 图片贴图文字（模型无关）

下面这套提示词按 **能力** 写，不绑定任何具体模型：凡是能吃参考图、能按指令编辑的
图像编辑/生成模型都能用。换模型只换调用方式，**提示词结构不用改**。

> 不要在本文件或 skill 里写死模型名、本地权重绝对路径、API 版本号。
> 每台电脑装的东西不一样，具体实现要放到「探测结果 / 可配置项」里。

### 最小版（短提示，够用）

```
保持图片格式、画幅比例和已有图案不变，只将图上的英文改成{lang_label}。
输出图片的像素宽高必须与输入完全一致（不要裁剪、不要改画幅、不要缩放画布）。
若原图有透明背景，保持透明，不要填充黑色。
请直接返回本地化后的图片本身，不要附加任何文字说明。
```

### 完整版（推荐：硬约束 + 文字清单 + 禁止项）

带文字清单能让漏字率明显下降，也能防止模型自作主张加词：

```
任务：把参考图上的英文替换为{lang_label}，这是一张 Minecraft 基岩版模组贴图。

必须严格遵守：
1. 输出像素宽高与输入完全一致，不裁剪、不缩放、不改画幅比例
2. 保持原有的透明通道；若输入有透明区域，输出该区域仍为透明
3. 除了下面列出的文字，图中其它任何元素都不得改变：
   背景、边框、插画、图标、光影、纹理、构图、字体风格
4. 逐条替换，不新增、不删除、不合并任何文字
5. 不要添加水印、签名、说明文字、英文残留
6. 译文若比原文长，允许缩小字号或折行，但不得超出原有文字区域的边界

需要替换的文字（按图中出现顺序）：
{text_list}

只返回处理后的图片本身。
```

### 分块编辑提示（保真度更高）

整图重绘容易让风格漂移，**crop → 编辑 → 贴回原坐标** 更稳：

```
这是参考图中的一个局部区域。请把区域内的英文替换为{lang_label}：
{text_list}

要求：只改文字；保持该区域内的背景、插画与字体风格不变；
输出宽高与输入一致；保持透明区域为透明。只返回图片本身。
```

### 常见失败与改法

| 症状 | 在提示词里补什么 |
|------|-----------------|
| 输出尺寸变了 | 把「像素宽高与输入完全一致」提到最前面，并禁止缩放 |
| 透明底变黑底 | 显式要求保持 alpha / 透明区域不填充 |
| 风格被重绘 | 强调「除文字外一切元素不变」，或改用分块编辑 |
| 漏字 / 多字 | 提供**完整文字清单**，并要求逐条替换、不新增不删除 |
| 字形漂移 | 指定「保持原字体风格」，仍有漂移就转 OCR 写回 |

尺寸对不上原图时**不要写回**——拉伸放大只会更糊，转
[image-localization.md](image-localization.md) 方案 B。

## OCR 取文字块 (bbox)

路线 B 第一步。**不依赖任何本地安装**：直接让多模态模型读图返回结构化结果。
（也可用 tesseract / PaddleOCR / Surya，输出格式保持一致即可。）

```
请检测图中所有文字区域，逐个给出原文与位置。

要求：
1. 输出 JSON 数组，每个元素：
   {"id":"T000","text":"原文","bbox":[x1,y1,x2,y2],"style":{"weight":"normal|bold","color":"#RRGGBB","align":"left|center|right"}}
2. bbox 使用【输入图的原始像素坐标】，格式 [左, 上, 右, 下]，左上角为原点
3. text 忠实转写看到的内容，不要翻译、不要纠错、不要补全
4. 同一段文字被换行拆开时合并成一条，bbox 取合并后的范围
5. 无法辨认的字符用 □ 占位
6. 只输出 JSON 数组，不要任何解释
```

## OCR 文字块翻译

```
下面是从图片中提取的文字块（JSON 数组，含原文与 bbox）。请把每条的 text 翻译为{lang_label}。

规则：
1. id 与 bbox 原样保留，只改 text
2. 译文尽量简短；比原文长时优先精简，不要自行加长
3. 专有名词、物品名、技能名使用游戏内通用的{lang_label}译名，保持全图一致
4. 数字、单位、版本号原样保留
5. text 为空或纯符号时保持不变
6. 只输出 JSON 数组，不要解释

待翻译：
{blocks_json}
```

译文若明显长于原文，渲染时要缩字号或折行，见
[image-localization.md](image-localization.md#5-渲染译文)。

## 批次建议

| 类型 | 建议批次大小 |
|------|-------------|
| .lang 条目 | 30–50 条/批 |
| 脚本字符串 | 20–30 条/批 |
| Display Name 回退 | 按文件数，通常 < 20 条 |
| 硬编码 displayNames 映射 | 按 category 分批（枚举、配置 label、状态、物品 fallback…） |
| 图上文字 | 整图重绘：1 张/次；分块编辑：每块一条文字清单 |
| OCR 文字块 | 20–30 条/批（bbox 随译文一起带出） |

## 硬编码 displayNames 映射表（步骤 3b）

用于从 constants / 配置表提取的 **logic id → 当前显示值**，输出供写入 `displayNameTables`：

```
你是 Minecraft 基岩版 Script 包本地化专家。
下面是从模组提取的「logic id → 当前英文显示值」映射（JSON 对象）。
请译为{lang_label}显示名，输出同结构的 JSON 对象。

规则：
1. 只翻译值（display label），键（logic id）原样保留，一个都不要改
2. 键可能是枚举 id、配置分类、状态码、建筑/职业类型等 — 一律视为不可改动的标识符
3. 保留值中的 § 颜色码；无颜色码则只译自然语言部分
4. "None" / "Unknown" / "Default" 等占位按游戏语境译
5. 不要输出解释，只输出 JSON 对象

输入：
{mapping_json}
```

**注意：** 若字符串同时用作 **object key** 或 **存档字段值**，JSON 的 key 字段必须保持原样；译文只用于 `getDisplayName(category, id)`，不得替换源码中的 id 字符串。

## 硬编码数组（纯 display 常量）

随机名池、纯描述列表等 **不参与 lookup** 的字符串数组：

```
下面是从模组提取的纯显示用英文字符串数组（JSON）。
请逐条译为{lang_label}，输出相同长度的 JSON 数组，顺序不变。
只输出 JSON 数组，不要解释。

{array_json}
```

## 译文质量校验

Agent 写回前应检查：

- `${` 出现次数与原文一致
- `§` 颜色码未被误删或改写
- lang 文件键名未被改动
- 脚本替换后括号/引号仍配对（可用 `node --check file.js`）
- 硬编码映射：**键名（logic id）** 仍为原始 id，**值** 为目标语言
- `getDisplayName(category, id)` 对未知 id 有合理 fallback（通常返回原 id）
- 贴图：输出宽高 **等于** 原图宽高；透明贴图的 alpha 未丢失；仍为 PNG
- 贴图：OCR 译文未溢出文字框、无原字残影、中文不是豆腐块
