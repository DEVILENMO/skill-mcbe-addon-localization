# MCBE 本地化 LLM 提示词模板

Agent 可直接使用或按任务微调以下模板。

## 语言文件 (.lang) 批量翻译

```
你是一名专业的 Minecraft 基岩版模组本地化专家。
请将下面的 .lang 语言文件内容翻译为{lang_label}。

规则：
1. 保持每行格式为 键=翻译后的值，一行一条，行数与输入完全一致
2. 只翻译等号右边的文字，等号左边的键原样保留
3. 保留 %s、%1$s、§c、§l、\\n 等占位符、格式代码、颜色代码完全不变
4. 实体名、物品名、技能名使用游戏内通用的{lang_label}译名
5. 如果值已经是{lang_label}或纯符号，保持不变
6. 不要输出任何解释、前言、结尾，只输出翻译后的行

待翻译内容：
{batch}
```

`{lang_label}` 示例：`简体中文`、`日本語`、`Deutsch`。

## Display Name 回退直译

当无法从 JSON 推导 lang key 时使用：

```
你是一名 Minecraft 基岩版模组本地化专家。
下面是无法标准化为语言文件 key 的 display_name 映射，每行格式为：相对路径=JSON字符串字面量。
请把每个等号右边的显示名翻译成{lang_label}，输出保持原格式（相对路径=JSON字符串），
只改值不改键。注意值需要用 JSON 字符串语法（引号包裹，转义 \\n、§ 颜色码等保留）。
直接输出全部翻译结果，不要任何解释。

内容：
{content}
```

## 脚本提示字符串

```
你是 Minecraft 基岩版模组脚本本地化专家。
下面是从 JS/TS 脚本中提取的玩家可见提示字符串（JSON 数组），请译为{lang_label}。

规则：
1. 只翻译人类可读文字；不要改动代码结构
2. 完整保留 § 及后续格式/颜色码（如 §c、§l、§r）、\\n、\\t
3. 完整保留 ${...} 模板插值、%s、%1$s、{{...}} 等占位符，位置与内容都不要改
4. 已是{lang_label}或纯符号的保持原样
5. 只返回 JSON 数组，每项格式 {"id":"S0000","text":"译文"}，id 与输入一致，不要其它说明

待翻译：
{batch}
```

## 图片贴图文字

```
保持图片格式、画幅比例和已有图案不变，只将图上的英文改成{lang_label}。
输出图片的像素宽高必须与输入完全一致（不要裁剪、不要改画幅、不要缩放画布）。
请直接返回本地化后的图片本身，不要附加任何文字说明。
```

## 批次建议

| 类型 | 建议批次大小 |
|------|-------------|
| .lang 条目 | 30–50 条/批 |
| 脚本字符串 | 20–30 条/批 |
| Display Name 回退 | 按文件数，通常 < 20 条 |
| 硬编码 displayNames 映射 | 按 category 分批（枚举、配置 label、状态、物品 fallback…） |

## 硬编码 displayNames 映射表（步骤 3b）

用于从 constants / 配置表提取的 **logic id → 当前显示值**，输出供写入 `displayNameTables`：

```
你是 Minecraft 基岩版 Script 包本地化专家。
下面是从模组提取的「logic id → 当前英文显示值」映射（JSON 对象）。
请译为{lang_label}显示名，输出同结构的 JSON 对象。

规则：
1. 只翻译值（display label），键（logic id）原样保留，一个都不要改
2. 键可能是枚举 id、配置分类、状态码、建筑/职业类型等 — 一律视为不可改动的标识符
3. 保留值中的 § 颜色码；无颜色码则只译自然语言部分
4. "None" / "Unknown" / "Default" 等占位按游戏语境译
5. 不要输出解释，只输出 JSON 对象

输入：
{mapping_json}
```

**注意：** 若字符串同时用作 **object key** 或 **存档字段值**，JSON 的 key 字段必须保持原样；译文只用于 `getDisplayName(category, id)`，不得替换源码中的 id 字符串。

## 硬编码数组（纯 display 常量）

随机名池、纯描述列表等 **不参与 lookup** 的字符串数组：

```
下面是从模组提取的纯显示用英文字符串数组（JSON）。
请逐条译为{lang_label}，输出相同长度的 JSON 数组，顺序不变。
只输出 JSON 数组，不要解释。

{array_json}
```

## 译文质量校验

Agent 写回前应检查：

- `${` 出现次数与原文一致
- `§` 颜色码未被误删或改写
- lang 文件键名未被改动
- 脚本替换后括号/引号仍配对（可用 `node --check file.js`）
- 硬编码映射：**键名（logic id）** 仍为原始 id，**值** 为目标语言
- `getDisplayName(category, id)` 对未知 id 有合理 fallback（通常返回原 id）
